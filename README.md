# Developer Documentation Portfolio
## Project Overview

This repository contains technical writing samples focused on developer documentation and API documentation.

The goal of this portfolio is to demonstrate the ability to:

- Write clear developer guides
- Document REST APIs
- Structure documentation for usability
- Provide examples and error handling

All documentation is written in Markdown and organized for easy navigation.
This repository contains documentation samples focused on developer guides and API documentation.
