# Getting Started Guide

This guide explains how to install and run a simple command-line tool.

## Prerequisites

Before starting, make sure you have:

- Python 3.10 or newer
- Access to a terminal or command prompt

## Installation

Install the tool using pip:

pip install example-tool

## Verify Installation

Run the following command:

example-tool --help

If the installation worked, you should see a list of available commands.

## Troubleshooting

If the command is not recognized, check that Python and pip are installed correctly.
