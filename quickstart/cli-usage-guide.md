# CLI Usage Guide

This document explains how to use a simple command-line interface (CLI) tool.

## Overview

The CLI tool allows users to run commands directly from the terminal.

## Basic Command

Run the following command:

example-tool run

This command starts the tool.

## List Available Commands

To see all available commands, run:

example-tool --help

This will display the list of commands supported by the tool.

## Example Workflow

1. Open the terminal.
2. Run the help command.
3. Choose the command you want to use.
4. Execute the command.

## Notes

Always check the help command first to understand the available options.
